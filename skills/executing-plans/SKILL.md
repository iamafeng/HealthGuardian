# Skill: Executing Plans

## Description
A disciplined approach to following and updating implementation plans.

## Instructions
- **Step-by-Step**: Execute tasks strictly according to the approved Plan.
- **Verification First**: After each task, run the specific verification steps (e.g., run a test, check a log).
- **Update on Divergence**: If the codebase reveals a mismatch with the Plan, PAUSE and update the Plan before continuing.
- **Documentation**: Record the results of each step in the plan file.

## Constraints
- Never skip a task or its verification.
- Never "wing it" when a plan is available.
