# Skill: Writing Plans

## Description
Standardizes the process of writing implementation plans for multi-step development tasks.

## Instructions
- **Assume Zero Knowledge**: Write plans assuming the executor (engineer) has zero prior knowledge of the codebase.
- **Micro-Tasks**: Break down each step into a 2-5 minute task.
- **Structure**:
  - **Header**: Feature name, goals, architecture, tech stack.
  - **Tasks**: For each task, specify:
    - Files involved.
    - Specific steps (code snippets, commands).
    - Expected output/Verification.
- **Location**: Save plans to `docs/plans/YYYY-MM-DD-<feature-name>.md`.

## Constraints
- Never start coding without a written and approved plan.
- Each task MUST include a verification step.
