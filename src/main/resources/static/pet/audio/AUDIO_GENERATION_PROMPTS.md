# Audio Generation Prompts for Pixel Pet Cat

Use these prompts with AI audio generation tools (ElevenLabs, Suno AI, etc.) or as search terms for free sound libraries.

## 1. bgm.mp3 (Background Music)
**Duration**: 30-60 seconds (loopable)

**Prompt**:
```
Create a cute, cheerful 8-bit/chiptune background music loop for a pixel art pet game. 
Upbeat tempo (120-140 BPM), major key, playful melody with simple harmony. 
Retro game console style (NES/Game Boy aesthetic). 
Instruments: square wave lead, triangle bass, simple percussion. 
Should loop seamlessly. Kawaii and relaxing mood.
```

**Keywords**: pixel game BGM, chiptune loop, kawaii music, retro game music, 8-bit happy

---

## 2. eat.wav (Eating Sound)
**Duration**: 0.5-1 second

**Prompt**:
```
Short, cute eating sound effect. Cartoon-style "nom nom" or chewing sound. 
Playful and satisfying. Slightly exaggerated, like a small animal eating. 
Clean, clear sound without background noise.
```

**Keywords**: eating sfx, nom sound, chewing, cartoon eat, cute munch

---

## 3. clean.wav (Cleaning/Bath Sound)
**Duration**: 1-2 seconds

**Prompt**:
```
Sparkling clean sound effect with water splash. Magical cleaning sound, 
like bubbles popping or water splashing gently. Light, bright tone. 
Could include a subtle "ding" or sparkle at the end. Cartoon style.
```

**Keywords**: water splash, sparkle sound, cleaning sfx, bubble pop, magic clean

---

## 4. work.wav (Working/Walking Away)
**Duration**: 1-2 seconds

**Prompt**:
```
Quick footstep sound effect, like a small character walking away. 
Light, quick steps (3-4 steps). Cartoon style, not realistic. 
Could be on wood or soft surface. Fading out slightly at the end.
```

**Keywords**: cartoon footsteps, walking away, quick steps, character movement

---

## 5. buy.wav (Purchase Sound)
**Duration**: 0.5-1 second

**Prompt**:
```
Positive purchase confirmation sound. Cheerful "cha-ching" or cash register sound. 
Retro game style, 8-bit aesthetic. Upbeat and satisfying. 
Could be a simple ascending chime or coin sound.
```

**Keywords**: purchase sound, cash register, cha-ching, buy sfx, coin register

---

## 6. meow.wav (Cat Meow)
**Duration**: 0.5-1 second

**Prompt**:
```
Cute, high-pitched cat meow. Kitten-like, friendly and playful. 
Not realistic - slightly stylized or cartoon-like. Short and sweet. 
Should sound happy and inviting when clicked.
```

**Keywords**: kitten meow, cute cat sound, cartoon meow, playful cat

---

## 7. coin.wav (Coin Pickup)
**Duration**: 0.3-0.5 seconds

**Prompt**:
```
Classic video game coin pickup sound. Bright, cheerful chime. 
8-bit/retro game style. Single note or quick ascending arpeggio. 
Satisfying "ding" sound. Similar to Mario coin sound but unique.
```

**Keywords**: coin pickup, game coin, retro ding, collect sound, item pickup

---

## 8. unlock.wav (Unlock/Achievement)
**Duration**: 1-2 seconds

**Prompt**:
```
Success/achievement sound effect. Triumphant fanfare or ascending chime. 
Retro game style, 8-bit aesthetic. Celebratory and rewarding. 
Could be a short melody (3-5 notes) that sounds victorious.
```

**Keywords**: achievement sound, unlock sfx, success fanfare, level up, victory sound

## File Format Notes

- **BGM**: MP3 format, 128-192 kbps, mono or stereo
- **SFX**: WAV format, 44.1kHz, 16-bit, mono preferred for smaller file size
- Keep file sizes small (<100KB for SFX, <1MB for BGM)
