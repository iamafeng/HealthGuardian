## 📥 下载步骤

### Pixabay (3个文件):

2. 点击绿色"Download"按钮
3. 下载完成后重命名为对应的文件名

### Freesound (5个文件):
1. 点击链接打开页面（你已登录）
2. 点击"Download"按钮
3. 选择下载格式（推荐WAV）
4. 下载完成后重命名为对应的文件名

## 🛠️ 文件处理建议

### 需要剪辑的文件:
- **clean.wav**: 使用Audacity等工具剪辑到1-2秒的闪光部分
- **buy.wav**: 剪辑提取短促的"咔嚓"或"叮"声（约0.5-1秒）

### 格式转换:
- **bgm.mp3**: 如果下载的是WAV格式，使用在线转换工具转为MP3
  - 推荐: https://cloudconvert.com/wav-to-mp3
  - 或使用Audacity: File → Export → Export as MP3
